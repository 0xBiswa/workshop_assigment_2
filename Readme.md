# DSA Workshop Assignment 2: Arrays & Linear Search

Welcome to **Assignment 2** of the DSA Workshop hosted by the **Coding Club NIT Nagaland**! This repository contains the problem statements and submission guidelines for your second assignment focusing on loops, array traversal, and linear search.

## 📝 Problem Statements

You need to solve the following 5 problems. You can use any programming language of your choice (C, C++, Java, Python, etc.).

1. **Sum of Array Elements:** Write a program that uses a loop to calculate and return the sum of all elements in an array.
2. **Find the Target (Linear Search):** Search for a `target` integer in an array using linear search. Return its index if found, or `-1` if it does not exist.
3. **Count Even Numbers:** Use a loop to count and return the total number of even integers present in an array.
4. **Find the Maximum Element:** Find and return the largest element in the array using a single loop traversal.
5. **Count Target Occurrences:** Return the number of times a specific `target` integer appears in the array.

> ⚠️** All submissions will be checked using automated code similarity tools. Do not copy code from peers. Please add brief comments to your code explaining your logic in your own words.**
